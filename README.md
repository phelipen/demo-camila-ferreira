# Camila Ferreira — demonstração não oficial

Proposta independente de Phelipe. Sem vínculo ou aprovação da clínica. Portfólio: https://phelipen.dev.

## Projeto

Next.js App Router, React, TypeScript e Tailwind CSS. Tipografia Bricolage Grotesque e DM Sans. O layout foi revisto para refletir a linguagem de autocuidado da marca: abertura tipográfica, vídeo do site atual, seletor de serviços, Gift Card ilustrativo e foto real do ambiente.

Requer Node.js 20.9 ou superior. Instalar: `npm ci`. Desenvolvimento: `npm run dev`. Verificações: `npm run typecheck` e `npm run build`.

O seletor atualiza a descrição e a mensagem de WhatsApp. O vídeo é silencioso, tem pausa e respeita movimento reduzido e economia de dados. Sem formulários, rastreamento, banco de dados ou credenciais no frontend. `noindex, nofollow` e aviso visível de demonstração. Agendamentos somente são confirmados pela empresa.
